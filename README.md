
# Enterprise WLAN AIOps Platform

An enterprise-grade Artificial Intelligence for IT Operations (AIOps) platform specifically tailored for WLAN infrastructure management. This repository follows a monorepo architecture designed for high scalability, real-time analytics, and automated network troubleshooting workflows.

##  Platform Architecture

- **`backend/`**: Core API application, automated services, models, and utility modules.
- **`frontend/`**: Interactive user interface containing source codes, public assets, and reusable components.
- **`simulator/`**: WLAN network emulator to simulate high-density wireless traffic and telemetry data.
- **`database/`**: Persistent storage management configurations for metrics, logs, and system states.
- **`workflows/n8n/`**: Automated network orchestration, alert filtering, and integration logic using n8n.
- **`docs/`**: Comprehensive system documentation including Work Instructions (WI), Software Requirement Specifications (SRS), System Architecture diagrams, and Entity-Relationship Diagrams (ERD).
- **`docker/`**: Individual deployment blueprints (`Dockerfile`) for system components.
- **`scripts/`**: Automation scripts for deployment, diagnostics, and testing.
